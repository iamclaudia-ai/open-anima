| `today.set_top`                   | `picks`                             | `date`                                                                                                                                                                                                                          | Set today's top picks (ordered, with a one-line reason each), replacing earlier picks for that date. Used by the morning sweep and the day refresh.                                                                                                                                                                                                                                                                                               |
| `today.snooze`                    | `until`                             | `id`, `key`                                                                                                                                                                                                                     | Snooze a Linear ticket (or a promise with a ticket) until a time, or unsnooze it with until=null.
